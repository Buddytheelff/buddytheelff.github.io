Network Engineering Lab Reflections

A collection of lab objectives, architecture decisions, and technical reflections from my Master's coursework at CU Boulder. Current Lab work is from CSCI/CYBR 5010: Data communication by Professor Levi Perigo

Network Automation: Python CLI & Remote Device Configuration

October 23, 2026 Network Automation
Python Netmiko SSHv2 GNS3 Linux

Objective

Learn how to accept user input and remotely access and configure network devices using Python automation libraries, simulating a scalable deployment to reduce manual CLI overhead.

Reflections & Key Takeaways

Writing this Python tool with argparse and Netmiko really drove home how tedious manual configuration can be when you scale beyond a single device. I learned quickly that managing command timing and buffer delays is essential when saving running configs over SSH so connections don't time out. For next steps, I'd definitely want to refactor the script to ingest target host configs from structured YAML or JSON files rather than manual prompts.

Lab 6: Packet Analysis & Deep Inspection with Wireshark

October 16, 2026 Packet Analysis
Wireshark TCP/IP HTTP ICMP Python

Objective

Observe and analyze network protocol operations in action across link, internet, and application layers, utilizing packet filters, custom profiles, continuous ring buffers, and Python pcap parsing.

Reflections & Key Takeaways

Seeing the TCP three-way handshake and HTTP requests dissected down to the byte level made abstract transport concepts much more concrete. Building dedicated Wireshark profiles and coloring rules showed me how much faster troubleshooting becomes when you strip away normal background traffic. Writing the small Python script to pull source and destination IPs straight out of a raw .pcap file was also a great exercise in packet-level inspection.

Lab 5: Static and Dynamic Routing (OSPF & Convergence)

October 9, 2026 Routing Protocols
OSPF Static Routing Failover Cisco IOS

Objective

Implement Cisco IOS static routing, floating routes with administrative distance, and dynamic link-state routing via OSPFv2 while evaluating topology convergence and failover.

Reflections & Key Takeaways

Configuring backup paths with floating static routes was a neat exercise, but watching OSPF calculate shortest paths and dynamically converge after a link drop made it obvious why dynamic routing is required at scale. Seeing just a single dropped packet during the physical failover test really demonstrated the efficiency of link-state protocols. Digging into Dijkstra's algorithm for node path cost calculations gave me a much stronger appreciation for how routing tables are actually derived.

Lab 4: VLANs, 802.1Q Trunking, and Inter-VLAN Routing

September 28, 2026 Switching & Trunking
VLANs 802.1Q Inter-VLAN Router-on-a-Stick

Objective

Configure switched broadcast domains with multiple VLANs, establish 802.1Q trunk links across switches, and implement inter-VLAN routing using router sub-interfaces.

Reflections & Key Takeaways

Setting up 'router-on-a-stick' and sub-interfaces gave me a clear picture of how Layer 2 separation interacts with Layer 3 boundaries to segment traffic without wasting physical router interfaces. Purposefully triggering a native VLAN mismatch was also a great sanity check on how trunk encapsulation behaves when untagged frames traverse the link. Tracing the ARP process between segregated VLANs really helped bridge the gap between switch frame forwarding and router routing logic.

Lab 1: Intro to Cisco and Spanning tree protocol or STP

September 7, 2026 Network Fundamentals
STP Cisco

Objective

"This lab will provide an introduction to Cisco IOS, and how to use the Command Line Interface (CLI). This lab is intended to be an overview of Cisco IOS, and switching technology - STP" Learn how to perform basic switch configuration & troubleshooting including: - switch password assignment and IOS nagivation - How to Activate/deactivate a port - How to change the speed and dulex of a port - How to verify the MAC address of computers connected to a specific port Review the usage of Spanning Tree Protocol (STP) including how switching environments behave regarding: - network failure - network loops

Reflections & Key Takeaways

This lab was a bit challenging becuase most of my experience with CLI comes from other Linux platforms like RouterOS and Junos OS. I also learned that STP is an effective tool in elminating loops within the network but can come at a cost. I am excited to learn more about STP and maybe ways that we can mitigate the issues that stem from its useage in a network.
