Network Engineering Lab Reflections

A collection of lab objectives, architecture decisions, and technical reflections from my Master's coursework at CU Boulder.

Lab 01: Enterprise Network Architecture Design

October 12, 2026 Network Architecture
OSPF BGP VLAN Topology

Objective

Design and simulate a multi-site enterprise redundant network backbone utilizing OSPF for internal routing and BGP for external internet gateway communication.

Reflections & Key Takeaways

Configuring failover path prioritization highlighted how subtle differences in cost metrics can cause asymmetric routing issues. Adjusting timer values on neighbors significantly reduced convergence time without overburdening CPU cycles on edge routers.

Lab 02: Network Automation with Python

November 01, 2026 Automation
Python Netmiko REST API

Objective

Develop scripts to automate VLAN creation and port allocation across multi-vendor switches using Netmiko and Paramiko libraries.

Reflections & Key Takeaways

Transitioning from manual CLI updates to script-driven deployment reduces human error during large rollout windows. Writing robust exception handling for SSH timeouts proved critical during testing.
